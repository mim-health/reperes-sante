# Repères Santé

Magazine santé grand public fondé sur des données vérifiées.

## V0
Cette première version est volontairement statique : HTML, CSS et JavaScript sans dépendance. Elle peut être modifiée depuis n'importe quel navigateur via GitHub/Codespaces et publiée facilement avec GitHub Pages.

### Principes éditoriaux
- aucun chiffre sans source identifiable ;
- priorité aux organismes publics et références médicales reconnues ;
- date et population étudiée précisées lorsque disponibles ;
- distinction explicite entre contenu validé et contenu de démonstration ;
- information générale, sans diagnostic personnalisé.

### Suite prévue
1. Validation des premiers contenus.
2. Publication GitHub Pages.
3. Ajout d'un flux éditorial privé Serper + OpenAI, avec validation humaine avant publication.
4. Ajout progressif de rubriques et d'articles.

## Lancer
Ouvrir `index.html` directement ou utiliser un serveur local simple.
