# MACA Next

## Vision

MACA est un magazine santé grand public permettant d'accéder à des informations fiables, pédagogiques et sourcées.

## Positionnement

MACA n'est pas :
- un outil de diagnostic ;
- un médecin IA ;
- un outil de triage.

MACA est :
- un magazine santé ;
- une bibliothèque de fiches validées ;
- une interface permettant de trouver facilement la bonne information.

## Principes

- informations compréhensibles ;
- sources médicales fiables ;
- réponses aux questions fréquentes ;
- expérience utilisateur moderne.

## Fonctionnalités prioritaires

### V1
- accueil magazine ;
- fiches santé ;
- catégories ;
- éditorial quotidien.

### V2
- assistant de navigation vers les fiches ;
- recherche conversationnelle.

## Architecture

Séparer clairement :

- composants d'affichage ;
- données éditoriales ;
- corpus médical ;
- styles ;
- navigation.

Objectif :
Créer une base simple, maintenable et évolutive.

## Règle

La version actuelle reste stable pendant la construction de MACA Next.
